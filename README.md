# 🤖 AI Personal Assistant

An AI-powered web application built using **Flask** and **OpenAI GPT-5** that allows users to ask general questions and summarize emails instantly.

---

## 🚀 Features

- 💬 Ask Anything using AI
- 📧 Email Summarization
- ⚡ Fast responses using OpenAI Responses API
- 🌐 Responsive Web Interface
- 🔒 Secure API key management using environment variables

---

## 🛠 Tech Stack

- Python
- Flask
- HTML

- OpenAI API
- python-dotenv

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Personal-Assistant.git
```

Go to project

```bash
cd AI-Personal-Assistant
```

Create virtual environment

```bash
conda create -n assistant python=3.12
```

```bash
conda activate assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file.

```env
OPENAI_API_KEY=your_openai_api_key
```

---

## ▶️ Run

```bash
python main.py
```

Open

```
http://127.0.0.1:5000
```

---

## 🔄 Application Workflow

1. User enters a question or email.
2. Flask receives the request.
3. OpenAI Responses API processes the input.
4. AI-generated response is returned.
5. Result is displayed instantly on the webpage.
